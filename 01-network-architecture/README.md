## Scope

Document the planned enterprise-style topology using the ISR 4331, two ASA 5516-X firewalls, Catalyst 3560-X, two Catalyst 3750 V2 switches and Catalyst 2960. Use draw.io for diagrams. Record physical connections, VLANs, IP addressing and device roles before deployment.
