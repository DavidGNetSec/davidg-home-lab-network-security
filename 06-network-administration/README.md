# DavidG Home Lab | Network Administration

[Back to project overview](../README.md)

## Scope

Use PuTTY and MobaXterm for device access, SolarWinds TFTP Server and the existing TFTP Server for isolated lab transfers, and Advanced Subnet Calculator for addressing. AnyDesk and UltraViewer are available for authorized remote desktop work. Verify installation and operation before use. Prefer secure transfers when supported.
