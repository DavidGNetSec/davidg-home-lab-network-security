# DavidG Home Lab | Network Monitoring & Analysis

[Back to project overview](../README.md)

## Scope

Use Wireshark for packet capture and protocol analysis and Nmap / Zenmap for authorized discovery and port scanning. Practice ARP, ICMP, DNS and TCP analysis; record findings. These tools provide on-demand analysis, not continuous monitoring. No Linux monitoring platforms are in scope.
